# 高校易占 · 周易起卦

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

欢迎！

面向**硕士、博士研究生**与**青年高校教师**的《周易》起卦参考工具。用铜钱、时间或数字起卦，得到本卦 · 互卦 · 之卦，并结合科研、导师、择业、考核、教学、心态等学术人群的日常处境，给出温和、审慎的解读（离线白话 + 可选 AI 解读）。

> 仅供传统文化学习与心理慰藉参考，不构成任何专业建议（医疗、心理、法律、职业决策等）。请理性看待结果。

## ✨ 功能特性

- **三种起卦方式**：铜钱起卦（手动摇六次）、时间起卦（梅花易数）、数字起卦（报两个数）
- **三卦齐看**：本卦（当下）→ 互卦（过程）→ 之卦（走向）
- **人群与场景**：可自选「研究生 / 青年教师」两类人群，并按身份细分场景（如导师关系 / 考核晋升），也可自动识别
- **AI 解读**：接入 OpenAI 兼容模型，支持多组 Key 自动容错；不配 Key 也能离线使用
- **历史记录**：本地保存最近 50 条起卦结果，可回看、删除
- **零依赖**：纯原生 HTML/CSS/JS + Node.js 内置模块，无需 `npm install`

## 🚀 快速开始

要求：Node.js ≥ 18。

```bash
# 1. 下载 / 克隆本项目
git clone <你的仓库地址>

# 2.（可选）配置 AI：复制模板并填入模型 Key
cp .env.example .env

# 3. 启动
npm start        # 或 node server.js
```

浏览器打开 <http://localhost:3000>。

> 不配置 `.env` 也能完整使用三种起卦、本/互/之三卦和离线解读；只有「AI 解读」需要模型 Key。

## 🎯 三种起卦方式

| 方式 | 说明 |
| --- | --- |
| 铜钱起卦 | 手动摇三枚铜钱六次，自下而上成卦（传统六爻） |
| 时间起卦 | 按当前公历年月日 + 地支时辰推算上下卦与动爻（梅花易数） |
| 数字起卦 | 输入两个正整数，分别推上卦、下卦，两数之和定动爻 |

## 🧭 本卦 · 互卦 · 之卦

- **本卦**：当下的局面
- **互卦**：由本卦第 2/3/4 爻（下卦）与第 3/4/5 爻（上卦）叠成，看发展过程中的内在态势
- **之卦**：由动爻变化而来，看走向

## 🎓 人群与场景

在提问旁可选「你的身份」（研究生 / 青年教师，默认「自动」），再按身份选「问题场景」。选定后，后端会用对应人群的语言组织解读。

**研究生（硕士/博士）**：学业科研 · 导师关系 · 经济生活 · 人际孤独 · 就业发展 · 心态认同

**青年高校教师（青椒）**：考核晋升 · 教学学生 · 学术行政 · 经济生活 · 身份认同 · 家庭失衡

## ⚙️ 模型配置

支持多组 OpenAI 兼容接口按编号从小到大自动容错（`_1` → `_2` → … 最多 `_20`）：

```env
OPENAI_API_KEY_1=你的key
OPENAI_BASE_URL_1=https://api.openai.com/v1
OPENAI_MODEL_1=gpt-4.1-mini
```

也兼容无编号配置（`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL`）。修改 Key 或模型后无需重启，下次请求自动生效。

## 🔒 安全配置

公开部署时，Key 只放在服务器 `.env`，绝不写进任何前端文件。后端内置限流、请求体大小、问题长度限制，以及提示词注入防护：

```env
AI_TIMEOUT_MS=30000
MAX_REQUEST_BYTES=32768
MAX_QUESTION_CHARS=300
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX=6
```

## 🌐 公网部署

- **自建服务器**：`node server.js`，前面加 Nginx / Caddy 做 HTTPS 与反向代理
- **Render / Railway / Fly.io 等 Node 平台**：上传项目，启动命令 `node server.js`，在平台环境变量里填模型 Key
- 部署只需这些文件：`index.html`、`styles.css`、`app.js`、`hexagrams.js`、`grad-context.js`、`server.js`、`铜钱.m4a`

## 🧪 数据校验

修改 `hexagrams.js` 后运行，校验 64 卦结构与八卦映射是否完整：

```bash
npm run validate
```

## ❓ 常见问题

- **AI 解读失败**：确认 `.env` 或平台环境变量里有可用的 `OPENAI_API_KEY_1` / `OPENAI_BASE_URL_1` / `OPENAI_MODEL_1`。
- **公网访问没有音效**：确认 `铜钱.m4a` 在项目根目录，且部署平台没有忽略该文件。
- **端口冲突**：在 `.env` 里设 `PORT=3001` 后重启。

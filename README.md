# 高校易占 · 心理树洞

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

欢迎！

面向**硕士、博士研究生**与**青年高校教师**的三个工具：一个用《周易》起卦做人生参考，一个用 AI 心理疏导做情绪支持，一个用语音对话做实时倾诉。

> 仅供传统文化学习与心理慰藉参考，不构成任何专业建议（医疗、心理、法律、职业决策等）。请理性看待结果。

## ✨ 项目组成

本项目由三个子功能组成，打开后的**首页**可点击进入：

### 1. 周易算卦

用《周易》为当下处境提供温和、审慎的参考。

- **三种起卦方式**：铜钱起卦（手动摇六次）、时间起卦（梅花易数）、数字起卦（报两个数）
- **三卦齐看**：本卦（当下）→ 互卦（过程）→ 之卦（走向）
- **人群与场景**：可选「研究生 / 青年教师」两类身份，各细分 6 个场景（如导师关系 / 考核晋升），也可自动识别
- **离线白话解释 + AI 解读**：不配 Key 也能起卦看离线解释，配了 Key 可让大模型结合你的问题与卦象生成个性化解读
- **历史记录**：本地保存最近 50 条起卦结果，可回看、删除

### 2. 心理树洞

一个可以倾诉、也可以与 AI 心理疏导助手聊天的情绪出口。

- **倾诉模式**（无 AI）：写下情绪存到本机，像把心事投进树洞；默认不发送给 AI
- **咨询模式**（AI 疏导）：AI 以心理疏导助手的身份共情、理清处境、给出可执行的建议
- **长期记忆**：AI 维护一份「用户长期画像」，随每次交流更新，**让你不必反复重提困境**（反复重提本身就是二次伤害）
- **透明可控**：画像可随时查看、编辑、清空

### 3. 倾听树洞

用**语音**和 AI 心理疏导助手对话，像打电话一样倾诉。

- **实时语音对话**：浏览器录音 → 阿里通义千问语音识别(ASR) → AI 疏导 → 通义千问语音合成(TTS) → 播放（语音 API 未配置时自动降级为文字模式）
- **共用长期记忆**：对话文字与「心理树洞」共用同一份用户画像，同样沉淀记忆
- 功能与「心理树洞」的咨询模式一致，只是交互方式改为语音

## 🚀 快速开始

要求：Node.js ≥ 18。除实时语音对话使用的 `ws` 外无第三方依赖，`npm install` 一次即可。

```bash
# 1. 下载 / 克隆本项目
git clone <你的仓库地址>

# 2.（可选）配置 AI：复制模板并填入模型 Key
cp .env.example .env

# 3. 启动
npm start        # 或 node server.js
```

浏览器打开 <http://localhost:3000>。

> 不配置 `.env` 也能完整使用三种起卦、本/互/之三卦、离线解读、心理树洞的倾诉模式；只有「AI 解读」和「咨询模式」需要模型 Key。

## 🧭 技术架构

### 前端

- 纯原生 **HTML / CSS / JavaScript**，无框架、无构建、无打包
- 所有交互（起卦动画、场景选择、历史记录、树洞对话）都在浏览器端完成
- 数据（起卦历史、倾诉、对话、用户画像）存于浏览器 **localStorage**，无需登录

### 后端

- 纯 **Node.js 内置 `http` 模块**，无 Express 等第三方框架
- 提供静态文件服务 + 三个 API 接口：`/api/interpret`（算卦 AI 解读）、`/api/counsel`（心理疏导）、`/api/remember`（更新记忆）
- 模型密钥只存在服务器 `.env`，绝不暴露到前端

### AI 能力

- 接入 **OpenAI 兼容接口**，支持**多组 Key 按编号自动容错**（`_1` → `_2` → … 最多 `_20`），一组挂了自动换下一组
- **提示词工程**：内置「研究生 / 青年教师」两类人群的场景知识库（`grad-context.js`），让同一卦象贴合不同处境来解读
- 心理疏导内置**危机安全红线**：识别自伤/自杀念头时引导求助热线、不诊断不开药、不煽动师生对抗

### 长期记忆

- AI 以一份结构化的**「用户长期画像」**（身份 / 当前处境 / 主要压力 / 情绪状态 / 已尝试的应对 / 重要进展 / 需要注意）持续记录用户处境
- 每次咨询（或倾诉时勾选「更新记忆」）都会更新画像，下次对话直接携带，**避免用户反复重提困境**
- 画像存本机、透明可编辑可清空

### 安全与隐私

- **提示词注入防护**：用户输入与记忆在提示词中显式声明为「数据而非指令」
- **限流**：按 IP + 接口限流，防止滥用消耗模型额度
- **输入校验**：请求体大小、文本长度、Content-Type 校验
- **隐私**：倾诉、对话、画像只存在本机浏览器，不跨设备同步；是否发送给 AI 由用户控制（咨询模式明确提示）


## ⚙️ 配置

支持多组 OpenAI 兼容接口按编号自动容错：

```env
OPENAI_API_KEY_1=你的key
OPENAI_BASE_URL_1=https://api.openai.com/v1
OPENAI_MODEL_1=gpt-4.1-mini
```

也兼容无编号配置（`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL`）。修改 Key 或模型后无需重启，下次请求自动生效。

「倾听树洞」的语音对话使用阿里通义千问（DashScope/百炼），预留：

```env
DASHSCOPE_API_KEY=你的通义千问语音key
```

未配置时，倾听树洞自动降级为文字模式，功能不受影响。

安全参数：

```env
AI_TIMEOUT_MS=30000          # 单次模型请求超时
MAX_REQUEST_BYTES=32768      # 请求体大小上限
MAX_QUESTION_CHARS=300       # 算卦问题长度上限
RATE_LIMIT_WINDOW_MS=60000   # 限流窗口
RATE_LIMIT_MAX=6             # 每窗口每接口请求上限
```

## 🌐 公网部署

- **自建服务器**：`node server.js`，前面加 Nginx / Caddy 做 HTTPS 与反向代理
- **Render / Railway / Fly.io 等 Node 平台**：上传项目，启动命令 `node server.js`，在平台环境变量里填模型 Key
- 部署所需文件：`index.html`、`styles.css`、`app.js`、`hexagrams.js`、`grad-context.js`、`counsel-context.js`、`server.js`、`铜钱.m4a`

## 🧪 数据校验

修改 `hexagrams.js` 后运行，校验 64 卦结构与八卦映射是否完整：

```bash
npm run validate
```

## ❓ 常见问题

- **AI 解读/咨询失败**：确认 `.env` 或平台环境变量里有可用的 `OPENAI_API_KEY_1` / `OPENAI_BASE_URL_1` / `OPENAI_MODEL_1`。
- **公网访问没有音效**：确认 `铜钱.m4a` 在项目根目录，且部署平台没有忽略该文件。
- **端口冲突**：在 `.env` 里设 `PORT=3001` 后重启。
- **换设备后记忆/历史没了**：所有数据都存在本机浏览器 localStorage，不跨设备同步。

# 大学院生のための易占 · 周易起卦

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

**修士課程・博士課程の大学院生**のための『周易』起卦リファレンス。銅銭・時間・数字で卦を立てて本卦・互卦・之卦を得て、研究・指導教員・就職・メンタルなど大学院生活に即した、穏やかで控えめな解釈を受け取れます（オフラインの平易な解説 + オプションの AI 解釈）。

> 伝統文化の学習と心の支えのための参考であり、専門的な助言（医療・心理・法律・キャリア等）ではありません。結果は理性的に受け止めてください。

## ✨ 機能

- **3 つの起卦方法**：銅銭起卦（6 回振る）、時間起卦（梅花易数）、数字起卦（2 つの数を伝える）
- **3 つの卦を一度に**：本卦（現在）→ 互卦（過程）→ 之卦（行く先）
- **大学院生向けシナリオ**：「研究 / 指導教員 / 就職 / 日常 / 人間関係 / メンタル」から選べる、自動判定も可
- **AI 解釈**：OpenAI 互換モデル、複数キーの自動フェイルオーバー、キーなしでもオフライン利用可
- **履歴**：直近 50 件の結果をローカル保存（閲覧・削除）
- **依存ゼロ**：素の HTML/CSS/JS + Node.js 標準モジュールのみ。`npm install` 不要

## 🚀 クイックスタート

Node.js ≥ 18 が必要です。

```bash
# 1. ダウンロード / クローン
git clone <リポジトリURL>

# 2.（任意）AI 設定：テンプレートをコピーしてキーを入力
cp .env.example .env

# 3. 起動
npm start        # または node server.js
```

ブラウザで <http://localhost:3000> を開きます。

> `.env` を設定しなくても、3 つの起卦方法・本卦/互卦/之卦・オフライン解説はすべて利用できます。「AI 解釈」だけがモデルのキーを必要とします。

## 🎯 3 つの起卦方法

| 方法 | 説明 |
| --- | --- |
| 銅銭起卦 | 三枚の銅銭を 6 回振り、下から上へ卦を組み立てる（伝統的な方法） |
| 時間起卦 | 現在の西暦年月日 + 地支の時刻から上下の卦と動爻を導く（梅花易数） |
| 数字起卦 | 2 つの正の整数を入力。1 つ目で上卦、2 つ目で下卦、合計で動爻を決める |

## 🧭 本卦・互卦・之卦

- **本卦**：現在の状況
- **互卦**：本卦の第 2・3・4 爻（下卦）と第 3・4・5 爻（上卦）から成り、進行中の内面的な様相を示す
- **之卦**：動爻の変化から導かれ、変化の方向を示す

## 🎓 大学院生向けシナリオ

質問の横でシナリオを選べます（デフォルトは「自動」）。選ぶと、バックエンドが大学院生活の言葉で解釈を組み立てます：

- **研究**：「成否」を「時期と準備」に読み替え、実行可能な小さな手順を示す
- **指導教員との関係**：正を守る・自衛・理性的な対話・明確な境界
- **就職**：代わりに決めず、判断の「軸」を示す
- **日常 / 人間関係 / メンタル**：軽やかで穏やか、気持ちを楽にする

## 📁 プロジェクト構成

```text
index.html               ページ構造

app.js                   起卦の操作、3 つの起卦アルゴリズム、シナリオ、履歴
hexagrams.js             64 卦、卦辞、キーワード、六爻の爻辞、八卦マッピング

.env.example             環境変数テンプレート
```

## ⚙️ モデル設定

OpenAI 互換の複数エンドポイントを番号順に自動フェイルオーバー（`_1` → `_2` → … 最大 `_20`）：

```env
OPENAI_API_KEY_1=your_key
OPENAI_BASE_URL_1=https://api.openai.com/v1
OPENAI_MODEL_1=gpt-4.1-mini
```

番号なしの設定（`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL`）にも対応。キーやモデルの変更は次回リクエストから反映され、再起動は不要です。

## 🔒 セキュリティ

公開デプロイ時、キーはサーバー側の `.env` にのみ置き、フロントエンドのファイルには決して書かないでください。バックエンドにはレート制限、リクエスト本体サイズ・質問長の制限、プロンプトインジェクション対策が組み込まれています：

```env
AI_TIMEOUT_MS=30000
MAX_REQUEST_BYTES=32768
MAX_QUESTION_CHARS=300
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX=6
```

## 🌐 公開デプロイ

- **自前サーバー**：`node server.js` を実行し、前に Nginx / Caddy を置いて HTTPS とリバースプロキシを提供
- **Render / Railway / Fly.io などの Node プラットフォーム**：プロジェクトをアップロードし、起動コマンドを `node server.js`、モデルのキーはプラットフォームの環境変数に設定
- デプロイに必要なファイルは次のみ：`index.html`、`styles.css`、`app.js`、`hexagrams.js`、`grad-context.js`、`server.js`、`铜钱.m4a`

## 🧪 データ検証

`hexagrams.js` を編集した後、64 卦の構造と八卦マッピングが揃っているか検証します：

```bash
npm run validate
```

## ❓ よくある質問

- **AI 解釈が失敗する**：`.env`（またはプラットフォームの環境変数）に有効な `OPENAI_API_KEY_1` / `OPENAI_BASE_URL_1` / `OPENAI_MODEL_1` があるか確認してください。
- **公開アクセスで音が出ない**：`铜钱.m4a` がプロジェクトルートにあり、プラットフォームに無視されていないか確認してください。
- **ポート競合**：`.env` で `PORT=3001` に設定して再起動してください。

# 大学院生のための易占 · 心の木の洞

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

ようこそ！

**大学院生（修士・博士）**と**若手大学教員**のための 3 つのツール：『周易』の起卦で人生の指針を得るツール、AI による心理的サポートで気持ちを吐き出す「心の木の洞」、音声でリアルタイムに語りかけられる「音声ツリーホール」です。

> 伝統文化の学習と心の支えのための参考であり、専門的な助言（医療・心理・法律・キャリア等）ではありません。結果は理性的に受け止めてください。

## ✨ プロジェクトの構成

3 つのサブ機能からなり、起動後の**ランディングページ**から選択して入ります。

### 1. 周易起卦

『周易』に基づき、いまの状況に対する穏やかで控えめな指針を提示します。

- **3 つの起卦方法**：銅銭起卦（6 回振る）、時間起卦（梅花易数）、数字起卦（2 つの数を伝える）
- **3 つの卦を一度に**：本卦（現在）→ 互卦（過程）→ 之卦（行く先）
- **対象とシナリオ**：「大学院生 / 若手教員」の 2 つの身分を選べ、それぞれ 6 つのシナリオ（指導教員との関係 / 評価・昇進など）に細分化。自動判定も可
- **オフライン解説 + AI 解釈**：API キーなしでも起卦とオフライン解説は利用可能。キーを設定すれば、質問と卦に応じた個別の解釈を大規模言語モデルが生成
- **履歴**：直近 50 件の起卦結果をローカル保存（閲覧・削除）

### 2. 心の木の洞（心理ツリーホール）

気持ちを吐き出したり、AI の心理サポートと対話したりできる情緒の出口です。

- **傾聴モード**（AI なし）：気持ちを書いてローカルに保存。心のうちを木の洞に投げ込むような感覚。デフォルトでは AI に送信しない
- **相談モード**（AI サポート）：AI が心理サポート役として共感し、状況を整理し、実行可能なアドバイスを提示
- **長期記憶**：AI が「ユーザー長期プロフィール」を維持し、対話のたびに更新。**つらい境遇を何度も語り直す必要がありません**（語り直すこと自体が二次的な傷になり得ます）
- **透明で制御可能**：プロフィールはいつでも閲覧・編集・消去できます

### 3. 音声ツリーホール

**音声**で AI 心理サポートと対話します。電話のように語りかけられます。

- **リアルタイム音声対話**：ブラウザで録音 → アリババ通義千問の音声認識(ASR) → AI サポート → 通義千問の音声合成(TTS) → 再生（音声 API 未設定時は自動的に文字モードへ）
- **共有の長期記憶**：対話の文字は「心の木の洞」と同じプロフィールに蓄積
- 機能は「心の木の洞」の相談モードと同じで、入力方法が音声になるだけ

## 🚀 クイックスタート

Node.js ≥ 18 が必要です。リアルタイム音声対話に使う `ws` 以外にサードパーティ依存はなく、`npm install` は 1 回で済みます。

```bash
# 1. ダウンロード / クローン
git clone <リポジトリURL>

# 2.（任意）AI 設定：テンプレートをコピーしてキーを入力
cp .env.example .env

# 3. 起動
npm start        # または node server.js
```

ブラウザで <http://localhost:3000> を開きます。

> `.env` を設定しなくても、3 つの起卦方法・本卦/互卦/之卦・オフライン解説・ツリーホールの傾聴モードはすべて利用できます。「AI 解釈」と「相談モード」だけがモデルのキーを必要とします。

## 🧭 技術アーキテクチャ

### フロントエンド

- 素の **HTML / CSS / JavaScript** のみ。フレームワーク・ビルド・バンドラー不使用
- 起卦アニメーション、シナリオ選択、履歴、ツリーホールの対話など、すべての操作はブラウザ側で完結
- データ（起卦履歴・傾聴・対話・プロフィール）はブラウザの **localStorage** に保存され、ログイン不要

### バックエンド

- Node.js 標準の **`http` モジュール**のみ。Express 等のフレームワーク不使用
- 静的ファイル配信 + 3 つの API：`/api/interpret`（易の AI 解釈）、`/api/counsel`（心理サポート）、`/api/remember`（記憶更新）
- モデルキーはサーバー側の `.env` にのみ置き、フロントエンドには一切露出しない

### AI

- **OpenAI 互換 API** に対応し、**複数キーの自動フェイルオーバー**（`_1` → `_2` → … 最大 `_20`）を実装
- **プロンプトエンジニアリング**：「大学院生 / 若手教員」の 2 つの層向けシナリオ知識ベース（`grad-context.js`）により、同じ卦を状況に応じて読み解く
- 心理サポートには**危機時の安全ライン**を内蔵：自傷・自殺の兆候を察知したら相談ホットラインへ誘導、診断・投薬はしない、指導教員との対立をあおらない

### 長期記憶

- AI が構造化された**「ユーザー長期プロフィール」**（身分 / 現在の状況 / 主なストレス / 感情状態 / 試した対処 / 進展 / 留意点）を継続的に記録
- 相談のたび（または傾聴時に「記憶を更新」をチェックした場合）に更新され、次の対話でそのまま利用。**つらい境遇を繰り返し語らせない**
- ローカル保存・透明・編集可能・消去可能

### セキュリティとプライバシー

- **プロンプトインジェクション対策**：ユーザー入力と記憶を「命令ではなくデータ」と明示
- **レート制限**：IP + エンドポイント単位で制限し、API 利用量の濫用を防止
- **入力検証**：リクエスト本体サイズ、テキスト長、Content-Type のチェック
- **プライバシー**：傾聴・対話・プロフィールはローカルブラウザにのみ保存。AI への送信はユーザーが制御（相談モードでは明示）

```text
hexagrams.js             64 卦、卦辞、キーワード、六爻の爻辞、八卦マッピング
grad-context.js          大学院生/若手教員のシナリオ知識ベース（起卦プロンプトに注入）

```

## ⚙️ 設定

OpenAI 互換の複数エンドポイントを番号順に自動フェイルオーバー：

```env
OPENAI_API_KEY_1=your_key
OPENAI_BASE_URL_1=https://api.openai.com/v1
OPENAI_MODEL_1=gpt-4.1-mini
```

番号なしの設定（`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL`）にも対応。キーやモデルの変更は次回リクエストから反映され、再起動は不要です。

「音声ツリーホール」の音声対話はアリババ通義千問（DashScope/百炼）を使用。予約済み：

```env
DASHSCOPE_API_KEY=your_qwen_voice_key
```

未設定の場合は文字モードに自動で切り替わり、機能はそのまま利用できます。

セキュリティパラメータ：

```env
AI_TIMEOUT_MS=30000          # 1 リクエストのタイムアウト
MAX_REQUEST_BYTES=32768      # リクエスト本体サイズの上限
MAX_QUESTION_CHARS=300       # 起卦質問の長さ上限
RATE_LIMIT_WINDOW_MS=60000   # レート制限ウィンドウ
RATE_LIMIT_MAX=6             # ウィンドウあたり・エンドポイントあたりの上限
```

## 🌐 公開デプロイ

- **自前サーバー**：`node server.js` を実行し、前に Nginx / Caddy を置いて HTTPS とリバースプロキシを提供
- **Render / Railway / Fly.io などの Node プラットフォーム**：プロジェクトをアップロードし、起動コマンドを `node server.js`、モデルのキーはプラットフォームの環境変数に設定
- デプロイに必要なファイル：`index.html`、`styles.css`、`app.js`、`hexagrams.js`、`grad-context.js`、`counsel-context.js`、`server.js`、`铜钱.m4a`

`hexagrams.js` を編集した後、64 卦の構造と八卦マッピングが揃っているか検証します：

```bash
npm run validate
```

## ❓ よくある質問

- **AI 解釈/相談が失敗する**：`.env`（またはプラットフォームの環境変数）に有効な `OPENAI_API_KEY_1` / `OPENAI_BASE_URL_1` / `OPENAI_MODEL_1` があるか確認してください。
- **公開アクセスで音が出ない**：`铜钱.m4a` がプロジェクトルートにあり、プラットフォームに無視されていないか確認してください。
- **ポート競合**：`.env` で `PORT=3001` に設定して再起動してください。
- **別端末で記憶・履歴が消える**：すべてのデータはローカルブラウザの localStorage に保存され、端末間では同期されません。
